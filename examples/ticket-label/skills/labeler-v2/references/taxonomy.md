# Taxonomie des labels

| Label | Définition | Exemple |
|---|---|---|
| bug | Le produit ne se comporte pas comme prévu | « Le bouton Export plante sur Safari » |
| feature | Nouvelle capacité qui n'existe pas | « Pouvoir exporter en PDF » |
| improvement | Évolution d'une capacité existante | « Ajouter un filtre de date à l'export » |
| performance | Lenteur ou consommation excessive, sans erreur | « L'export met 40 s pour 1000 lignes » |
| security | Faille, fuite de données, contrôle d'accès | « Un utilisateur voit les exports d'une autre équipe » |
| documentation | Doc absente, fausse ou incomplète | « Le README ne décrit pas l'export » |
| needs-triage | Information insuffisante pour classer | « Ça marche pas » |
